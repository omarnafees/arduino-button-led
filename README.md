# arduino-button-led

A simple Arduino Uno project where a push button controls an LED.

## What I Learned

In this project, I learned how to use `digitalRead()` to read a button and `digitalWrite()` to control an LED. I also learned how to wire a push button with a pull-down resistor and how HIGH and LOW signals work. I practiced troubleshooting when the button input was behaving unexpectedly.

## Components

Arduino Uno
Push button
LED
220Ω resistor
10kΩ resistor
Breadboard
Jumper wires

## How It Works

When the button is pressed, the Arduino detects a HIGH signal and turns the LED on. When the button is released, the Arduino detects a LOW signal and turns the LED off.

## Code

The Arduino code is included in `button-led.ino`.

## Project

This project helped me understand how Arduino receives an input from a physical component and uses that input to control an output.
